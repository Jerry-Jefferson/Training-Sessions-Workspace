# Root Cause First

- Capture expected and observed behavior plus a repeatable reproduction before editing when possible.
- Read complete errors, stack traces, console/network evidence, and recent relevant changes.
- Form falsifiable hypotheses and gather evidence that discriminates between them.
- State the proved root cause before applying one minimal fix.
- Add regression coverage and rerun the focused check.
- Escalate architecture or broad implementation changes instead of hiding them inside debugging.
