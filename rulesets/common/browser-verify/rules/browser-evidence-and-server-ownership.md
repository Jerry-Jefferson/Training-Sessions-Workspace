# Browser Evidence And Server Ownership

- Use a supplied or emitted URL; never assume a host or port.
- Ask before starting a development server and record the exact process and emitted URL.
- Stop only the process started by the current role.
- Verify relevant interactions, focus, keyboard, responsive reflow, long content, and user-visible states.
- Inspect console and network evidence and report exact URLs, viewports, steps, and failures.
- Never edit application code or data to make browser verification pass.
