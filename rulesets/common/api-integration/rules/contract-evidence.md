# Contract Evidence

- Distinguish confirmed backend behavior from assumptions, proposals, mocks, and blocked details.
- Prefer machine-readable schemas, generated clients, backend documentation, and observed responses over remembered contracts.
- Never promote a provisional endpoint, payload field, status, or error to living specification truth.
- Keep provisional mocks visibly labelled and traceable to the unresolved question they simulate.
- Record which owner must confirm each blocked contract element.
