# Evidence-First Review

- Review the requested diff against an explicit base and relevant requirements, not the whole repository by default.
- Lead with reproducible defects, behavioral regressions, security/accessibility failures, contract breaks, and missing meaningful tests.
- Give each finding a severity, tight file/line reference, and concrete failure scenario.
- Distinguish repository rules from personal style preferences and avoid speculative findings without evidence.
- A PASS verdict still names residual runtime or coverage gaps.
