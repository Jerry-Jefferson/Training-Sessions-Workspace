# Common Ruleset

Framework-neutral frontend guidance shared by ruleset-aware skills.

- Skill sections may contain authored rules and an optional `INDEX.md`.
- `shared/` contains cross-skill or vendored rules.
- A missing skill section is valid.
- When an index exists, it may reference files only inside this Common Ruleset root.
- Core skill authority, safety, approvals, and STOP behavior override all rules.
