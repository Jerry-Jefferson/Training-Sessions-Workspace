# Active Framework Ruleset: React

This replaceable framework pack contains project-agnostic React and TypeScript guidance.

- Vendored rule bodies under `shared/` are unchanged pinned copies.
- Skill-local `INDEX.md` files are authored routing surfaces.
- Stack-specific project choices such as Vite, Next.js, TanStack Query, shadcn/Tailwind, mandatory i18n, test runner, and repository layout do not belong here.
- A non-React project may remove or replace this whole directory.
- Missing Framework sections are valid; skills continue with Common and Project guidance.
